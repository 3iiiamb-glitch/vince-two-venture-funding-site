DEPLOY TO RAILWAY
1. Upload this folder to a GitHub repository, or use Railway's preferred source connection.
2. Create a Railway project and choose Deploy from GitHub Repo.
3. Railway will detect package.json and run `npm start`.
4. Generate a public domain in Railway Settings > Networking.

No build command or external dependencies are required. Railway supplies the PORT variable automatically.
